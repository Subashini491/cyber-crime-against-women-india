# Cyber Crime Against Women in India — Data Analysis Dashboard

## Project Overview
An independent data analysis project examining state-wise cyber crimes against women across 28 Indian states using official government data sources.

## Objective
To analyse patterns in cyber crimes against women in India and identify high-risk states using population-adjusted metrics rather than raw crime numbers alone.

## Key Findings
- Karnataka records the highest cyber crime rate at 18.85 per lakh women — significantly higher than all other states
- Population-adjusted analysis reveals hidden high-risk states like Mizoram (+17 rank change) and Goa (+14 rank change)
- 75% of reported cyber crimes fall under the broad NCRB category "Other Crimes Against Women"
- Among specifically classified offences, Cyber Pornography (2,382 cases) and Cyber Stalking (1,211 cases) are most prevalent
- Raw crime numbers alone are misleading — Uttar Pradesh appears dangerous in raw numbers but drops 13 ranks after population adjustment

## Dashboard Pages
- **Page 1** — Overview: KPIs, top states by crime volume, crime type breakdown
- **Page 2** — Population-Adjusted Analysis: Crime rate per 1 lakh women, rank change comparison
- **Page 3** — Crime Pattern Analysis: State-wise crime type heatmap, national distribution
- **Page 4** — Key Findings and Data Sources

## Tools Used

## Data Sources
- **Crime Data:** National Crime Records Bureau (NCRB), Crime in India Report
- **Female Population:** Population Projections for India and States 2011–2036, National Health Mission (NHM)
